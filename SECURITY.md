# Security Policy

## Supported versions

AxisAgentic is under active development. Security fixes are applied to the
`main` branch and included in the next release. Please make sure you are running
the latest version before reporting an issue.

## Reporting a vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

Instead, use one of the following private channels:

- Preferred: open a private advisory through GitHub's
  [security advisory reporting](https://github.com/XYZ-AI-Lab/AxisAgentic/security/advisories/new).
- Or email **hello@xyz-lab.ai** with the details.

Please include as much of the following as you can:

- A description of the vulnerability and its potential impact
- Steps to reproduce, or a proof-of-concept
- Affected version, commit, or configuration
- Any suggested mitigation, if known

## What to expect

- We will acknowledge your report within a reasonable time frame.
- We will investigate and keep you informed of our progress.
- Once a fix is available, we will coordinate a disclosure timeline with you and
  credit you in the release notes unless you prefer to remain anonymous.

Thank you for helping keep AxisAgentic and its users safe.
